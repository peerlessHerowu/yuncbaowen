# 爆款标题（Title）· 功能打磨设计文档

---

## 一、现状分析

### 1.1 当前实现

- 输入：主题 + 可选风格 + 数量（1-20，默认 12）
- 输出：标题列表，每条有 `text`（标题）和 `type`（套路类型）
- 套路覆盖：悬念式、数字式、反差式、痛点式、福利式、共鸣式

### 1.2 问题

**P0**
1. 套路类型只有 6 种，实际上爆款标题套路有 20+ 种
2. 没有「标题质量评估」（哪些标题更有可能爆）
3. 不支持「指定套路」（用户想要 5 个数字式、3 个悬念式，做不到）
4. 不支持「参考标题」（给一篇文章的标题，生成类似风格的）

**P1**
1. 生成结果不能排序（不知道哪个更好）
2. 没有「一键选标题」流程（选完标题后，应该直接跳到定向生成）
3. 没有收藏/标记功能（好的标题怎么保存）
4. 没有 AB Test 提示（多个标题可以测试哪个效果更好）

**P2**
1. 标题没有「预期点击率」参考（哪种套路历史上点击率更高）
2. 没有「避免重复」功能（下次生成应该避开上次已经用过的套路）

### 2.2 标题评分系统

生成标题后，用规则给每个标题评分：

```typescript
function scoreTitleClickRate(title: string): number {
  let score = 60  // 基准分

  // 加分项
  if (/\d+/.test(title)) score += 5          // 有数字
  if (title.length >= 15 && title.length <= 25) score += 5  // 合适长度
  if (/？|为什么|如何|怎么/.test(title)) score += 5  // 疑问
  if (/你|我/.test(title)) score += 3          // 人称代词（共鸣）
  if (/竟然|居然|原来|其实/.test(title)) score += 5  // 意外词
  if (/免费|不花钱|白嫖/.test(title)) score += 3  // 利益词
  if (/第一|最好|最快/.test(title)) score -= 5   // 违禁词

  return Math.min(Math.max(score, 0), 100)
}
```

## 四、UI 设计规范

### 点击率颜色
- 80+：金色 `#F59E0B` + ⭐
- 70-79：绿色 `#10B981`
- 60-69：蓝色 `#3B82F6`
- <60：灰色 `#6B7280`

### 套路徽章
每种套路用不同颜色的小徽章：
- 悬念式：紫色
- 数字式：蓝色
- 反差式：橙色
- 痛点式：红色
- 福利式：绿色
