# 文章排版（Layout）· 功能打磨设计文档

---

## 一、现状分析

### 1.1 当前实现

看前端代码 `LayoutPage.tsx`：基本上是一个空页面或极简实现，功能几乎没有。

这是**得分最低的功能（3.3/10）**，也是**差异化机会最大的功能**。

### 1.2 用户需求

自媒体创作者在写完文章后，需要：
1. 对文章进行**排版格式化**（标题层级、分段、字体大小）
2. **一键复制到微信公众号**（保留格式）
3. **添加配色主题**（不同颜色风格的标题、分割线）
4. **插入图片占位符**（知道哪里需要配图）

### 1.2 竞品分析

| 工具 | 核心价值 | 缺陷 |
|------|---------|------|
| 秀米 | 丰富的公众号模板 | 操作复杂，学习成本高 |
| 135 编辑器 | 专业排版 | 需要会员，价格贵 |
| 壹伴 | 编辑器 + 素材 | 功能堆砌 |

**机会点：** 简单、快速、AI 辅助，专注公众号场景。

## 二、设计方案

### 2.1 三栏布局

```
┌──────────────┬─────────────────────────────┬────────────────────┐
│ 排版设置     │ 编辑区                       │ 预览区              │
│              │                              │                     │
│ 主题颜色     │ 粘贴或输入文章...            │ [手机预览]          │
│ ○ 默认黑白   │                              │                     │
│ ○ 商务蓝     │ # 一级标题                  │  文章预览           │
│ ○ 活力橙     │ ## 二级标题                 │                     │
│ ○ 清新绿     │                              │  ═══ 一级标题 ═══  │
│              │ 正文段落...                  │                     │
│ 标题样式     │                              │  正文...            │
│ ○ 居中加粗   │                              │                     │
│ ○ 左对齐带线 │                              │  [复制到公众号]     │
│ ○ 彩色背景块 │                              │                     │
│              │ [AI 智能排版]               │                     │
└──────────────┴─────────────────────────────┴────────────────────┘
```

### 2.2 AI 智能排版

一键 AI 分析文章结构，自动：
1. 识别标题层级（H1/H2/H3）
2. 识别需要加粗的关键词
3. 建议分割线位置
4. 建议哪些段落适合加引用样式

### 2.3 微信公众号一键复制

这是最关键的功能，需要：
1. 将 Markdown/HTML 转换为富文本
2. 保持字体、颜色、样式
3. 复制到剪贴板后，可以直接粘贴到公众号编辑器

```typescript
// 核心技术：document.execCommand('copy') + 富文本选中
function copyToWechat(html: string) {
  const div = document.createElement('div')
  div.innerHTML = html
  div.style.position = 'absolute'
  div.style.left = '-9999px'
  document.body.appendChild(div)

  const range = document.createRange()
  range.selectNodeContents(div)
  const selection = window.getSelection()
  selection?.removeAllRanges()
  selection?.addRange(range)

  document.execCommand('copy')
  document.body.removeChild(div)
}
```

### 2.4 排版主题

预设 5 个开箱即用的排版主题：
1. **简约黑白**：纯文字，简洁大气
2. **商务蓝**：蓝色系，专业感
3. **活力橙**：橙色系，年轻活泼
4. **清新绿**：绿色系，清爽自然
5. **暗夜紫**：深色背景，高端感
