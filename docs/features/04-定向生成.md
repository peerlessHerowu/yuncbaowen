# 定向生成（Generate）· 功能打磨设计文档

---

## 一、现状分析

### 1.1 当前实现

- 输入：主题 + 可选风格 + 可选知识库 + 字数
- 输出：SSE 流式，逐字打印
- 支持关联知识库文档

### 1.2 问题（代码审计）

**P0**
1. 前端 SSE 流式接收到了，但 UI **没有实现逐字打印效果**
   - 代码：接收到 `onChunk` 但直接 `setContent(prev => prev + chunk)`，会闪烁
   - 应该用 `requestAnimationFrame` 控制更新频率
2. 「停止生成」按钮：UI 上没有这个按钮，一旦开始无法停止（AbortController 未实现）
3. 生成失败时 SSE 连接断开，前端没有错误状态显示

**P1**
1. 没有「字数进度」显示（生成了多少字、还剩多少）
2. 知识库选择 UI 很简陋（只有一个多选列表）
3. 没有「生成历史」快速复用（相同主题要重新填写所有参数）
4. 没有生成效果的实时质量评估（生成完了立刻看 AI 味评分）

**P2**
1. 字数设置只有 Input，没有快捷选项（500/1000/1500/2000 字）
2. 没有「文章结构模板」选择（总分总 / 问题引入 / 故事引入等）

## 二、优化方案

### 2.1 真实流式打字机效果

```typescript
// 当前（有问题）：
onChunk: chunk => setContent(prev => prev + chunk)

// 优化：使用 requestAnimationFrame 批量更新
const pendingChunks = useRef<string[]>([])
const flushRef = useRef<number>()

const handleChunk = (chunk: string) => {
  pendingChunks.current.push(chunk)
  if (!flushRef.current) {
    flushRef.current = requestAnimationFrame(() => {
      setContent(prev => prev + pendingChunks.current.join(''))
      pendingChunks.current = []
      flushRef.current = undefined
    })
  }
}
```

### 2.2 停止生成

```typescript
const abortRef = useRef<AbortController>()

async function generate() {
  abortRef.current = new AbortController()
  // 传入 signal 到 fetch
  ...
}

function stopGenerate() {
  abortRef.current?.abort()
  setLoading(false)
}
```

## 四、UI 设计规范

### 生成状态
- 等待中：空状态卡片 + 引导文字
- 生成中：逐字出现 + 底部进度 + 停止按钮
- 已完成：完整文章 + 操作按钮组

### 文章预览区
- 字体：`font-serif` 或 `font-sans`（可切换）
- 行高：`leading-relaxed`（1.625）
- 段落间距：`space-y-4`
