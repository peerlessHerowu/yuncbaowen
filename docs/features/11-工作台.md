# 工作台（Dashboard）· 功能打磨设计文档

---

## 一、现状分析

### 1.1 当前实现

- 顶部统计卡片（今日创作数/总标题数/总文章数/风格数）
- 功能快速入口（6 个卡片）
- 最近创作历史
- 5 步爆文工作流引导

### 1.2 问题

**P0**
1. 统计数据用途不明（今日创作 3 篇，对用户的意义是什么）
2. 工作流引导（5步）是静态文字，没有根据用户实际完成情况动态变化
3. 没有「今日推荐」（用户打开工作台，不知道今天该干什么）

**P1**
1. 最近创作只显示标题，没有内容预览
2. 没有「继续上次」（最近的未完成项目）
3. 快速入口卡片样式千篇一律
4. 没有今日热点摘要

**P2**
1. 没有数据趋势（本周创作 vs 上周）
2. 没有个性化推荐（基于用户常用功能）

## 二、优化方案

### 2.1 智能今日推荐

```
┌───────────────────────────────────────────────────────────┐
│  👋 早上好，peerless                                       │
│                                                           │
│  今日推荐                                                 │
│  ┌─────────────────┐  ┌─────────────────────────────────┐ │
│  │ 🔥 今日热点     │  │ 📝 继续昨天的文章               │ │
│  │ AI编程助手爆火  │  │ 《用AI提升工作效率》             │ │
│  │ 3800万讨论     │  │ 已完成 60%，点击继续             │ │
│  │ [以此创作]     │  │ [继续编辑]                      │ │
│  └─────────────────┘  └─────────────────────────────────┘ │
└───────────────────────────────────────────────────────────┘
```

### 2.2 工作流进度（动态）

根据用户实际数据显示进度：
```
你的爆文工作流

① 选热点    ✅ 已完成（今天查看了 12 条热点）
② 生成标题  ✅ 已完成（今天生成了 8 个标题）
③ 写文章    ⏳ 进行中（点击开始）
④ 去AI味   ○ 未开始
⑤ 多平台分发 ○ 未开始
```

### 2.3 功能入口卡片重设计

每张卡片：大图标 + 功能名 + 一句话价值 + 今日使用次数：
```
┌──────────────────────────────┐
│  🔥                          │
│  热点追踪                     │
│  今天有 3 个热点适合你        │
│                              │
│  今日使用 2 次                │
└──────────────────────────────┘
```

## 四、UI 设计规范

### 整体色调
工作台用渐变背景（顶部深色渐变到页面浅色）：
```css
background: linear-gradient(180deg, #0f172a 0%, #1e293b 30%, transparent 100%)
```

### 问候语
- 6-11 时：「早上好」
- 11-14 时：「午安」
- 14-18 时：「下午好」
- 18-22 时：「晚上好」
- 22-6 时：「夜深了，」
