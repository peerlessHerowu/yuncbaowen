# 全局 UI 设计规范

---

## 一、现状问题

### 1.1 代码审计发现

1. **颜色系统不统一**：各页面用 `text-indigo-400`、`text-brand-400`、`text-blue-400` 混用
2. **组件复用率低**：卡片、标签、按钮有多套实现
3. **动画效果单调**：几乎只有 `animate-fade-in`
4. **空状态缺失**：多数页面没有内容时是空白
5. **错误状态缺失**：只有 toast，没有 inline error
6. **移动端适配不足**：大部分页面没有响应式设计

## 二、设计系统建立

### 2.1 色彩系统

```
主色调（品牌色）：
- brand-500: #6366F1  (indigo)
- brand-400: #818CF8
- brand-600: #4F46E5

语义色：
- success: #10B981 (emerald-500)
- warning: #F59E0B (amber-500)
- error:   #EF4444 (red-500)
- info:    #3B82F6 (blue-500)

背景层级（深色模式）：
- dark-900: #0F172A  ← 最底层背景
- dark-800: #1E293B  ← 页面背景
- dark-700: #334155  ← 卡片背景
- dark-600: #475569  ← 悬浮卡片
- dark-500: #64748B  ← 边框/分割线
```

### 2.2 间距系统

```
xs:  4px   (p-1)
sm:  8px   (p-2)
md:  12px  (p-3)
lg:  16px  (p-4)
xl:  20px  (p-5)
2xl: 24px  (p-6)
3xl: 32px  (p-8)
```

### 2.3 字体规范

```
标题：
- 页面大标题：text-2xl font-bold
- 区块标题：text-lg font-semibold
- 卡片标题：text-base font-medium

正文：
- 主要内容：text-sm text-slate-200
- 次要说明：text-xs text-slate-400
- 标签：text-[10px] text-slate-500

等宽（代码/数据）：font-mono
```

### 2.4 圆角系统

```
小组件（Tag、Badge）：rounded-full 或 rounded
按钮：rounded-xl
卡片：rounded-2xl
对话框：rounded-3xl
```

## 三、组件规范

### 3.1 卡片（Card）

**标准卡片：**
```tsx
<div className="bg-dark-700 border border-dark-600 rounded-2xl p-5">
  {children}
</div>
```

**可悬停卡片（可点击）：**
```tsx
<div className="bg-dark-700 border border-dark-600 rounded-2xl p-5
                hover:border-brand-500/50 hover:bg-dark-600
                transition-all duration-200 cursor-pointer">
  {children}
</div>
```

**高亮卡片（已选中）：**
```tsx
<div className="bg-brand-500/10 border border-brand-500/30 rounded-2xl p-5">
  {children}
</div>
```

### 3.2 按钮

**主按钮：**
```tsx
<button className="flex items-center gap-2 px-4 py-2.5 rounded-xl
                   bg-brand-500 hover:bg-brand-600
                   text-white text-sm font-medium
                   transition-colors duration-150
                   disabled:opacity-50 disabled:cursor-not-allowed">
```

**次按钮（描边）：**
```tsx
<button className="flex items-center gap-2 px-4 py-2.5 rounded-xl
                   border border-dark-500 hover:border-brand-500/50
                   text-slate-300 hover:text-brand-400
                   bg-transparent hover:bg-brand-500/5
                   text-sm transition-all duration-150">
```

**幽灵按钮（纯文字）：**
```tsx
<button className="text-slate-400 hover:text-slate-200
                   text-sm transition-colors duration-150">
```

### 3.3 输入框

```tsx
<textarea className="w-full bg-dark-700 border border-dark-500
                     rounded-xl px-4 py-3
                     text-slate-200 text-sm
                     placeholder-slate-500
                     focus:outline-none focus:ring-2 focus:ring-brand-500/50
                     focus:border-brand-500/30
                     resize-none transition-all" />
```

### 3.4 徽章（Badge）

```tsx
// 成功
<span className="px-2 py-0.5 rounded-full text-[10px] font-medium
                 bg-emerald-500/15 text-emerald-400">
  ✅ 已通过
</span>

// 警告
<span className="px-2 py-0.5 rounded-full text-[10px] font-medium
                 bg-amber-500/15 text-amber-400">
  ⚠️ 需优化
</span>

// 错误
<span className="px-2 py-0.5 rounded-full text-[10px] font-medium
                 bg-red-500/15 text-red-400">
  ❌ 有问题
</span>
```

### 3.5 空状态

每个列表/结果区域都需要空状态设计：
```tsx
<div className="flex flex-col items-center justify-center py-16 text-center">
  <div className="text-4xl mb-4 opacity-50">{icon}</div>
  <h3 className="text-slate-300 font-medium mb-1">{title}</h3>
  <p className="text-slate-500 text-sm mb-4">{description}</p>
  <button className="btn-primary">{actionLabel}</button>
</div>
```

## 四、动画规范

### 4.1 进入动画

```css
/* 基础淡入 */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* 滑入（从右） */
@keyframes slideIn {
  from { opacity: 0; transform: translateX(20px); }
  to   { opacity: 1; transform: translateX(0); }
}

/* 弹出 */
@keyframes popIn {
  from { opacity: 0; transform: scale(0.95); }
  to   { opacity: 1; transform: scale(1); }
}
```

### 4.2 加载状态

```tsx
// 骨架屏
<div className="h-4 bg-dark-600 rounded animate-pulse" />

// 转圈
<Loader2 className="animate-spin text-brand-400" />

// 打字机（流式文字）
<span className="border-r-2 border-brand-400 animate-pulse">|</span>
```

### 4.3 交互反馈

```
点击按钮：scale(0.97) → 100ms → scale(1)
复制成功：绿色 Check 图标 → 2s → 恢复原图标
删除确认：抖动动画（shake）
加载完成：绿色勾 → 1s → 内容渐入
```

## 五、页面结构规范

### 5.1 标准页面头部

```tsx
<div className="space-y-5 animate-fade-in">
  {/* 页面头部 */}
  <div className="section-header">
    <div className="flex items-center gap-3 mb-1">
      <Icon size={20} className="text-brand-400" />
      <h1 className="section-title mb-0">{title}</h1>
      {badge && <span className="badge">{badge}</span>}
    </div>
    <p className="section-desc">{description}</p>
  </div>

  {/* 功能区域 */}
  <div className="card p-5 space-y-4">
    {/* 输入区 */}
  </div>

  {/* 结果区（有数据时显示） */}
  {results && (
    <div className="animate-slide-up">
      {/* 结果展示 */}
    </div>
  )}
</div>
```

### 5.2 响应式断点

```
移动端（< 768px）：
- 侧边栏隐藏（底部导航或汉堡菜单）
- 卡片全宽
- 双列变单列

平板（768px - 1024px）：
- 侧边栏折叠（只显示图标）
- 卡片 2 列

桌面（> 1024px）：
- 完整侧边栏
- 最大宽度 1440px，居中显示
```

## 六、交互设计规范

### 6.1 反馈时机

| 操作 | 反馈方式 | 时机 |
|------|---------|------|
| 点击按钮 | 按钮 loading 状态 | 立即 |
| 请求成功 | Toast 成功提示 | 请求完成后 |
| 请求失败 | Toast 错误提示 + 按钮恢复 | 失败时 |
| 表单校验错误 | 输入框边框变红 + 提示文字 | 提交时 |
| 复制成功 | 图标变绿 + 「已复制」 | 立即 |
| 删除操作 | 确认对话框 | 点击后 |

### 6.2 关键交互流程

**流式生成（SSE）的 UI 状态机：**
```
空闲 → [点击生成] → 
加载中（按钮loading，显示进度）→ 
流式输出（逐字显示，停止按钮可用）→
完成（显示操作按钮组）

任意状态 → [点击停止] → 停止（保留已生成内容）
任意状态 → [请求失败] → 错误（显示重试按钮）
```

### 6.3 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + Enter` | 提交/生成 |
| `Escape` | 关闭对话框 |
| `Ctrl/Cmd + C` | 复制当前结果 |
