## 跨功能核心问题（需所有文档关注）

### 1. URL 自动抓取
所有接受「文章内容」的接口已支持粘贴 URL 自动抓取正文，但前端没有视觉提示。
**解法：** 输入框增加 URL 自动识别提示（检测到 URL 时显示「将自动抓取正文」）

### 2. 流式输出体验
定向生成、二次仿写使用 SSE 流式，但 UI 没有逐字打印效果，用户看到的是等待后一次性出现。
**解法：** 前端实现真实的流式打字机效果

### 3. 空状态设计
多数页面没有内容时显示空白，体验差。
**解法：** 每个页面都设计引导性空状态

### 4. 错误反馈
当前错误全部走 toast，不区分严重程度和可操作性。
**解法：** 区分 toast（临时提示）、inline error（表单验证）、error state（功能不可用）

### 5. 内容历史关联
创作历史和各功能页面是割裂的，历史里的内容无法一键送入相关功能继续加工。
**解法：** 历史记录支持「继续优化」快捷入口

## 执行计划

按优先级顺序执行各功能文档中的优化方案：

1. **第一批（1-2天）**：去AI味 + 内容检测（最核心差异化功能）
2. **第二批（1-2天）**：热点追踪 + 多平台推文（用户最频繁使用）
3. **第三批（2-3天）**：风格复刻 + 定向生成 + 二次仿写（创作核心链路）
4. **第四批（1天）**：文章排版（目前最薄弱）
5. **第五批（1天）**：工作台 + UI 设计规范（整体体验提升）
