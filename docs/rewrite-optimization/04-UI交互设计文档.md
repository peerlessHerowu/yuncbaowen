# 二次仿写降重 - UI/交互设计文档

> 版本：v2.0 | 日期：2026-08-16
> 设计系统：Tailwind CSS + 暗色主题 + 品牌绿(#22c55e)

---

## 一、设计原则

| 原则 | 说明 |
|------|------|
| 信息密度适度 | 不堆砌选项，通过折叠/分组降低认知负荷 |
| 即时反馈 | 每个操作都有视觉响应（hover/active/loading） |
| 结果导向 | 用户最关心「相似度多少」，放在最醒目位置 |
| 渐进式披露 | 基础功能一目了然，高级选项渐进展开 |
| 一致性 | 复用现有设计系统的组件样式（card/btn/input） |

## 三、组件设计

### 3.1 降重状态栏（DedupStatusBar）

**位置**：结果面板内顶部，改写完成后显示

**状态**：
- `idle`：不显示
- `rewriting`：显示进度条动画 + 「AI 改写中...」
- `checking`：显示扫描动画 + 「检测连续词...」
- `fixing`：显示修补动画 + 「优化修补中 (3处)...」
- `done`：显示最终相似度

**视觉设计**：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌── done 状态 ──────────────────────────────────────┐  │
│  │                                                    │  │
│  │  ● 预估相似度                                     │  │
│  │    ┌────────────────────────────┐                  │  │
│  │    │  3.2%  ✓ 原创             │  ← 大字 + 绿色  │  │
│  │    └────────────────────────────┘                  │  │
│  │    已修补 2 处连续词 · 仅供参考                    │  │
│  │                                                    │  │
│  └────────────────────────────────────────────────────┘  │
│                                                         │
│  ┌── rewriting 状态 ─────────────────────────────────┐  │
│  │                                                    │  │
│  │  ⟳ AI 改写中...                                   │  │
│  │  ████████████░░░░░░░░░░░░  45%                    │  │
│  │                                                    │  │
│  └────────────────────────────────────────────────────┘  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**颜色编码**：
- 相似度 < 5%：`text-emerald-400` + `bg-emerald-500/10`
- 相似度 5-10%：`text-amber-400` + `bg-amber-500/10`
- 相似度 > 10%：`text-red-400` + `bg-red-500/10`

**进度条**：
- 使用品牌绿渐变：`bg-gradient-to-r from-brand-600 to-teal-400`
- 高度 3px，圆角
- 流式输出时进度条缓慢前进（非精确，视觉感受为主）

## 四、动效与微交互

### 4.1 进度条动画

```css
/* 进度条骨架 */
.progress-bar {
  @apply h-[3px] rounded-full bg-dark-500 overflow-hidden;
}

/* 进度条填充（渐变 + 动画） */
.progress-fill {
  @apply h-full rounded-full transition-all duration-500 ease-out;
  background: linear-gradient(90deg, #16a34a 0%, #2dd4bf 100%);
}

/* 改写中的脉冲效果 */
.progress-fill.streaming {
  animation: progressPulse 2s ease-in-out infinite;
}

@keyframes progressPulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.7; }
}
```

### 4.2 相似度数字动画

改写完成时，相似度数字从 0 递增到最终值（count-up 动效）：

```typescript
// 数字递增动画（300ms）
function animateNumber(target: number, onUpdate: (n: number) => void) {
  const duration = 300
  const start = performance.now()
  function tick(now: number) {
    const progress = Math.min((now - start) / duration, 1)
    const eased = 1 - Math.pow(1 - progress, 3) // ease-out-cubic
    onUpdate(+(target * eased).toFixed(1))
    if (progress < 1) requestAnimationFrame(tick)
  }
  requestAnimationFrame(tick)
}
```

### 4.3 状态栏入场

```
idle → rewriting: slide-down + fade-in (200ms)
rewriting → checking: 进度条变色 (品牌绿→琥珀色) + 文字切换
checking → done: 进度条填满 → 收缩为相似度数字 (300ms)
```

### 4.4 降重提示条入场

选中降重意图时：
- `animate-slide-up`（从下方 10px 滑入 + 透明度 0→1）
- 时长 200ms

取消选中时：
- 高度折叠为 0 + 透明度 0（150ms）

### 4.5 结果替换动画（修补后）

当修补层替换了部分内容时：
- 不做全文替换的闪烁
- 直接平滑替换内容，用户几乎感知不到

## 五、响应式设计

### 5.1 断点策略

| 断点 | 布局变化 |
|------|---------|
| ≥ 1024px（默认） | 双栏并排 |
| 768px - 1023px | 双栏但宽度 60/40 分配 |
| < 768px | 单栏堆叠（原文在上，结果在下） |

### 5.2 移动端适配

- 改写目标从 4 列网格变为 2 列
- 强度选择从 3 列变为横向滚动
- 双栏变单栏时，结果面板展开后原文面板可折叠

## 六、视觉细节打磨

### 6.1 卡片层次感

```
背景色层次（从远到近）：
body:        bg-dark-100 (#0f1117)
card:        bg-dark-200 (#161b22) + border-dark-500
内部区块:    bg-dark-300 (#1c2128)
高亮选中:    bg-teal-500/10
```

### 6.2 相似度数字排版

- 数字：`text-2xl font-bold tabular-nums`
- 百分号：`text-sm opacity-60`
- 标签：`text-xs text-slate-500`

```jsx
<div className="flex items-baseline gap-1">
  <span className="text-2xl font-bold text-emerald-400 tabular-nums">3.2</span>
  <span className="text-sm text-emerald-400/60">%</span>
</div>
<span className="text-[10px] text-slate-500">预估相似度</span>
```

### 6.3 选中态视觉强化

当前选中态是 `bg-teal-500/10 border-teal-500/30`，升级为：
- 左侧加一条 2px 的品牌绿竖线（active indicator）
- 选中文字加粗

```jsx
<div className={cn(
  'relative p-3 rounded-xl border transition-all',
  selected
    ? 'bg-teal-500/10 border-teal-500/30 before:absolute before:left-0 before:top-3 before:bottom-3 before:w-0.5 before:bg-brand-500 before:rounded-full'
    : 'bg-dark-300 border-dark-500'
)}>
```

### 6.4 空状态优化

结果面板空状态增加视觉引导：


## 七、可访问性

- 所有交互元素有 `aria-label`
- 进度条有 `role="progressbar"` + `aria-valuenow`
- 颜色对比度 ≥ 4.5:1（WCAG AA）
- 键盘可操作：Tab 聚焦、Enter 触发
