## 1. 技术选型

### 1.1 整体方案

本项目为**纯静态落地页**，无需后端服务，目标是：
- 首屏 LCP ≤ 1.5s
- 零依赖构建（单 HTML 文件可独立运行）
- 可选 CDN 加速部署

### 1.2 技术栈

| 层 | 技术 | 理由 |
|---|-----|-----|
| 结构 | 原生 HTML5（语义化标签） | 零依赖，SEO 友好 |
| 样式 | 原生 CSS3（Custom Properties + Grid/Flex） | 无需构建工具，CSS 变量支持主题切换 |
| 动画 | CSS Keyframes + JS IntersectionObserver | 60fps，无需第三方库 |
| 粒子背景 | Canvas API（原生 JS） | 轻量，可控 |
| 字体 | Google Fonts CDN（思源黑体/Inter） | 中英文最优渲染 |
| 图标 | Lucide Icons CDN（SVG sprite） | 轻量，样式可控 |
| 部署 | GitHub Pages / Vercel | 免费 CDN 节点 |

## 3. 性能优化策略

### 3.1 加载性能

| 优化点 | 方案 |
|-------|-----|
| 字体加载 | `<link rel="preconnect">` + `font-display: swap` |
| 图片 | 全部使用 CSS 渐变/SVG，无 bitmap 图片 |
| JS 执行时机 | `DOMContentLoaded` 后执行，非阻塞 |
| CSS 动画 | 仅 `transform` + `opacity` 触发，不触发重排 |
| Canvas 粒子 | `requestAnimationFrame` + 粒子数量动态适配屏幕 |

### 3.2 渲染性能

```
动画触发原则：
  ✅ transform: translate / scale / rotate
  ✅ opacity
  ❌ width / height / top / left（触发 layout）
  ❌ background-color 逐帧变化（用 opacity 遮罩替代）

滚动动画：
  IntersectionObserver threshold: 0.15
  → 元素进入视口 15% 时触发 fade-in-up
  → 使用 CSS class 切换（不用 JS 直接操作 style）
```

### 3.3 移动端优化

```css
/* 触摸设备关闭悬停效果，防止粘着 */
@media (hover: none) {
  .card:hover { transform: none; }
}

/* 减少动画（用户系统设置尊重） */
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; }
}
```

## 4. 安全设计

### 4.1 XSS 防护
- 页面无动态内容注入，无 `innerHTML` 赋值用户输入
- 外部链接全部 `rel="noopener noreferrer"`

### 4.2 CSP 头（部署时配置）
```
Content-Security-Policy:
  default-src 'self';
  style-src 'self' 'unsafe-inline' fonts.googleapis.com;
  font-src fonts.gstatic.com;
  script-src 'self' 'unsafe-inline' unpkg.com;
  img-src 'self' data:;
```

### 4.3 隐私
- 无 Cookie、无 LocalStorage
- 无第三方 Tracker/Analytics（落地页版本）
- 外部资源仅限 Google Fonts + Lucide CDN
