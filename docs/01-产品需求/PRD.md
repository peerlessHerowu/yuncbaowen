## 1. 产品概述

### 1.1 产品定位

「云创一键爆文」是面向**公众号/头条创作者**的 AI 写作助手 SaaS 工具，核心价值主张：
> 从热点选题到成稿发布，一条流水线，去 AI 味，爆款率高。

### 1.2 目标用户

| 用户类型 | 特征描述 | 核心痛点 |
|---------|---------|---------|
| 个人自媒体 | 每周更新 2-5 篇，时间有限 | 选题难、写稿慢、AI 味重被限流 |
| MCN 运营团队 | 多账号批量运营，效率优先 | 风格统一、多平台适配、降本增效 |
| 企业新媒体 | 品牌宣传，注重合规 | 违禁词风险、原创度不足、排版繁琐 |
| 内容服务商 | 接稿生产，交付质量要求高 | 客户风格复刻、快速定稿 |

### 1.3 竞品对比

| 对比维度 | 本产品 | 竞品A（秘塔写作猫） | 竞品B（笔灵AI） |
|---------|-------|------------------|----------------|

## 2. 核心功能模块

### 2.1 SOURCING — 选题·找爆点

#### 2.1.1 热点追踪
- **数据源**：聚合微博/知乎/抖音/头条全网热榜
- **展示规则**：按内容赛道自动归类（科技/情感/财经/娱乐/健康...）
- **置顶逻辑**：热度破万自动置顶，红色高亮显示
- **操作入口**：每条热点右侧提供「起标题」「写全文」一键按钮
- **刷新频率**：5分钟增量更新，支持手动刷新

#### 2.1.2 爆款标题生成
- **输入**：用户输入主题关键词（1-50字）
- **输出**：批量生成 10-15 个不同套路标题
- **套路覆盖**：悬念式 / 数字式 / 反差式 / 痛点式 / 福利式 / 共鸣式
- **交互**：列表展示，一键复制，支持继续生成

### 2.2 WRITING — 创作·出爆文

#### 2.2.1 风格复刻
- **输入**：粘贴 1-5 篇参考文章链接
- **处理**：AI（Claude Opus 4.8）深度拆解写作风格指纹
- **输出**：生成专属风格提示词 Prompt，永久保存至个人风格库
- **复用**：在「定向生成」中选择风格一键调用

#### 2.2.2 定向生成 + 知识库引用
- **输入**：选定风格 + 输入主题
- **知识库**：勾选后 AI 基于上传的本地资料写作，有据可查
- **输出**：完整公众号正文，结构清晰，有头有尾

#### 2.2.3 二次仿写
- **输入**：原文粘贴（支持 URL 或文本）
- **输出**：语义等价但文字面貌焕然一新的新稿
- **场景**：降重、改写、同主题不同风格

#### 2.2.4 多平台推文
- **输入**：一份公众号素材
- **输出**：自动适配公众号/小红书/微博/知乎/抖音口播/朋友圈/视频号 7 个平台
- **调性差异**：各平台语气/格式/长度自动匹配

### 2.3 QUALITY — 质检·更真更稳

#### 2.3.1 去 AI 味闭环
- **检测方式**：启发式 AI 痕迹评分（0-100分）
- **改写触发**：自动检测 → 改写 → 重检，最多3轮
- **停止条件**：评分达标（默认 ≥80分）或达到最大轮次
- **结果展示**：每轮评分变化，改写前后对比

#### 2.3.2 可解释内容检测
- **四维报告**：AI味 / 违禁词 / 原创度 / 可读性
- **定位到句**：每处扣分点精确定位，高亮显示
- **深度检测**：支持接入用户自己的模型 Key 做「AI深度检测」
- **批量支持**：可对多篇文章批量检测

#### 2.3.3 本地知识库 RAG
- **上传格式**：TXT / MD / DOCX / PDF
- **检索机制**：纯本地关键词检索（无需 embedding Key）
- **存储上限**：单用户 50MB（BYOK后无限制）
- **使用场景**：生成时勾选「引用知识库」，AI 引用资料写作

### 2.4 PUBLISH — 成稿·直接发

#### 2.4.1 排版 + 封面
- **Markdown渲染**：秒变精美公众号图文格式
- **主题**：提供 6 套配色主题（极简白/深夜蓝/暖橙/薄荷绿...）
- **封面卡片**：一键生成 900×383 纯排版封面，可配背景色/标题/副标题

#### 2.4.2 创作历史
- **自动归档**：所有生成内容按时间倒序归档
- **操作**：回看 / 复制 / 删除 / 「送去去AI味」/ 「送去检测」/ 「送去排版」
- **搜索**：按关键词或时间段筛选

#### 2.4.3 多模型 BYOK + 故障切换
- **支持模型**：DeepSeek / 通义 / Kimi / 智谱 / GPT / Claude / Gemini
- **Key存储**：AES-256加密，仅本地存储，不上传服务器
- **故障切换**：检测到服务商限流/宕机自动切换下一个
- **用量统计**：每个Key的Token消耗可视化展示

## 5. 非功能需求

### 5.1 性能
- 落地页首屏加载 ≤ 1.5s（LCP）
- 所有动画帧率 ≥ 60fps
- 移动端适配（320px - 1920px）

### 5.2 安全
- 模型 Key AES-256 本地加密，禁止上传
- 无 XSS 漏洞（CSP 策略）
- HTTPS 强制

### 5.3 可访问性
- AA 级色彩对比度
- 键盘可导航
- 屏幕阅读器友好（语义化 HTML）
